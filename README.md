# yusufaf/homebrew-tap

Homebrew formulae for [yusufaf](https://github.com/yusufaf) projects.

```bash
brew install yusufaf/tap/sfn-diagram
```

`Formula/sfn-diagram.rb` is generated and pushed automatically by the release
workflow in [yusufaf/sfn-diagram](https://github.com/yusufaf/sfn-diagram); do not
edit it by hand.
